# 使用书中的性情、职业、健康、婚育、富贵与流年

这些主题实际进入学习与对照流程。使用时需要同时读到作者主张、全部条件和相反解释，不把原作者的话悄悄删弱，也不把它升级成从个人照片测出的事实。

| 查询 | 原书位置与主张范围 | 怎么用 |
|---|---|---|
| `study 性情` | 掌型、指掌与拇指配合，头脑线图例；PDF19—32、60—64 | 解释传统分类及其配合条件；不输出真实人格、智力或可信度 |
| `study 职业` | 例103/104、图198/199；PDF74右 | 完整保留太阳线起点、手形或头脑线条件；不从单线判个人天赋、职业资格或成败 |
| `study 健康` | 正文PDF43、75与附录二PDF155左，对健康线给相反解释 | 比对冲突，讲明作者各自说法；不判病、体质、寿命或康复日期 |
| `study 婚育` | 结合线PDF77—78与一重纹PDF121等 | 核视角、条数及章节；不把线数等同婚次，不判断生育、忠贞或伴侣命运 |
| `study 富贵` | 玉柱/太阳PDF71—74，古诀修正PDF94、96、99 | 解释来路、呈现与名禄的传统主题；保留古代官位/金额的比喻修正，不换算收入与估值 |
| `study 流年` | 结合线年龄段PDF78、指节五岁法PDF132 | 明确量尺与部位，不拼接成未实现的个人日历算法 |

实际读掌时：先列看见的形态，再核所引用图例是否全部满足。如果原书需要太阳线从头脑线起，就必须看到这个连接。性情、职业等作者论断以原作者归属表达，不能把“书这样说”写成“照片证明你如此”。个人经历不能反过来补纹。

日常文字可以一开始明确传统文化解读语境，随后直接讲已成立的形态与解释。对影响核心判断的缺口用一句话交代，不用反复免责声明代替解读，也不以省去限定换取肯定语气。

完整模式中的五个主题可以逐一对照；没有足够形态的主题保持未判。当前`study`没有个人照片输入，也不把历史主题自动加入`analyze.matches`。观察、传统解释、现实事实和未来结果保持分层。
