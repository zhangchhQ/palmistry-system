# 怎样把知识练成实际能力

## 内化的验收标准

不以记住多少句断语衡量。遇到没看过的图，能够认清位置、说出形态前提、处理相反证据、组合成可读解释，并在纠正后完整重算，才算掌握了一项方法。

当前的长期载体是规则、程序、技能和测试；没有做模型权重训练。技能可以把程序化方法复用到后续读掌中，来源只在有争议时回查。[官方技能文档](https://learn.chatgpt.com/docs/build-skills)

## 每个知识单元怎样晋级

1. **已读**：原文已读，知道语境、图号和是否有矛盾。
2. **可定义**：能用位置、走向、连接和反例区分它与相似形态。
3. **可执行**：进入明确规则；缺前提就不触发。
4. **可复核**：不同人可根据同一标注核查；正例、反例及混淆项通过。
5. **真人识图已验**：取得明确授权的标注集，独立留出未见照片，分别统计左右手、主线、符号表现。
6. **解释已验**：隐藏生活背景后读图，再由用户评定清楚、具体、无套话，并保留不贴合的反馈。

这些等级逐项记录。一个规则测试通过，不把同章所有图例一并晋级。

## 整本书的覆盖办法

全书各章都有覆盖记录；每条知识区分为形态定义、传统解释、流派冲突、历史断语或不可用个人推断。不能将不采用某项医学/人格断语说成漏读，也不能把整章已读说成164例、72式都已程序化。

0.2.0已补看全部169个文件页，并把516个编号图组转成514条形态记录。局部被黑条挡住的笔画保留未决，不能用同名古诀补画。具体口径见[图例转化](figure-conversion.md)。

后续缺口是细形态的可执行门、独立真人识图和白话盲评。逐项辨认、原书断语判断与预测验证分别记录；把扫描复印进仓库、堆更多近义句都不能替代这些检验。

## 针对已经暴露的错误练习

- 本人标注与模型手别相反：本人标注优先。
- 纠正左/右后：所有观察归属和双手比较重新计算。
- 线看不清：退回未确认，不借机解释为事业不明。
- 主线围成三角：不认成独立三角符。
- “智慧纹”跨附录：先分清太阳线与头脑线。
- 健康线、火星丘、结合线说法相反：保留冲突，不选一句配合期待。
- 同一形态被多个近义名命中：按同一观察保留来源，不称多法印证。

回归用例全部合成；没有保存真实用户照片或个人资料。

## 表达也要练

先用两三句话说清这次象意的主调，再解释两三个决定性形态，最后点出会改变结论的一个条件。日常解读不逐段引书，不堆术语，也不在每句话末尾重复免责声明。已读取的讲课整理、经典案例与GitHub比较，以及原创练习见[表达学习](expression-study.md)。

玄学表达可以有画面感，例如“积累慢慢接成一条路”“做事与被看见接在一起”。前提仍是相应形态实际清楚；不把用户已经讲过的人生经历改写成看手看出来的。

## 尚未启用的路线

- 自动掌纹分割：先评估获授权标注数据与独立测试，再决定是否需要模型训练。
- 模型微调：当前没有数据授权、训练任务或验收集，不自动上传资料或发起付费训练。
- 公开开源：先确定许可证与分发范围，源书和个人影像始终排除。
