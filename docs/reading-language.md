# 清楚、有依据的看相表达

目标是把观察、传统判断和关键条件连成一段话。主判断、决定性依据与转折适量加粗，每段只强调一两处；原理紧跟判断，不另插“顺带教你”。

先把这次所问的事回答到证据允许的程度，再说明在哪里看见、哪条规则改变了读法。没有具体判断条件的“积累、坚持、做深”不拿来填篇幅。读掌时不把现有项目分工或经历包装成从手上看出来的内容。

## 组合的轻重怎样讲

整手背景提供条件，主线决定所讨论的主题，连接与修饰项决定解释怎样改变。多个相似名词仍可能只是一条观察；同图两条玉柱须分开，太阳线要指明接在哪一条。

原课和历史案例教的是“改变一个条件，解释就跟着改”。这比多背一套肯定词更重要。原书个别断语中的性情、能力、健康或财富主张仍属于原作者，不提升为个人事实。

## 原创合成练习

以下不是用户手相，也不是老师原话。

**假设：玉柱已确认中断，后段从旁边接起。**

这条线要分前后两段看。前一段在这里停住，后一段从旁边接上，传统上把这一组图读作**换路再起**。判断的关键在两段怎样衔接；一条细纹横穿而主线仍相连，属于另一种形态。

**改变条件：只有中间一段清楚，起点不见。**

这一段看得清，来路还没有认出。月丘起线与生命线起线，在原书中是两条不同解释。**起点未明，来路先留空。**中段连续只按形态说，不推出明年收入稳定。

**假设：头脑线下斜，太阳线从同一条头脑线发出。**

这幅图的重点在两线接头。太阳线从下斜头脑线上发出，陈氏例104把它联系到诗文等创作主题。**这条解释由两项条件共同成立。**只有头脑线下斜时，不套用图199的整段职业解释。

## 不同完成状态分别讲

- 读完整字幕：说明字幕类型、单元范围；没有连续看视频就不说听完原课。
- 历史作者讲完一个人：说明事后回忆与图文来源；不称事前预测被证实。
- 程序检查通过：只证明所列行为，不能称学会预测。
- 用户认可表达：只表示该版好懂，不证明判断事实正确。
